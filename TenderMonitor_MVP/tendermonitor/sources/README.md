# Адаптеры источников

Подключать источник следует только после проверки официального способа доступа,
формата данных, авторизации и условий использования. Не обходить CAPTCHA и
ограничения площадок. Секреты не хранить в исходном коде.

## Реестр (`registry.py`)

`config/source_urls.txt` содержит строки «Метка: URL». `read_sources()` разбирает
их (комментарии `#` и пустые строки пропускаются), `classify_source()` определяет
тип каждого URL, `collect_all()` собирает по всем источникам и один раз обновляет
Excel. Ошибка одного источника изолируется и не валит остальные; по каждому
логируются статус, найдено/импортировано/отфильтровано/пропущено и лимиты.

Типы источников:

| Тип | Пример | Обработка |
|---|---|---|
| `eis` | `zakupki.gov.ru` | сбор через `eis_browser.run_once` (Edge → RSS) |
| `open_data_file` | прямая ссылка `.csv/.zip/.xlsx` | `open_data.import_open_data` |
| `open_data_catalog` | `data.gov.ru`, `rlw.gov.ru/opendata` | поиск прямых файлов данных; ближайший набор импортируется только если колонки распознаются как закупочные (`source_id`+`title`); наборы-указатели и SPA-каталоги пропускаются с логом |
| `portal_unsupported` | `zakupki.gov39.ru` | проверка доступности, пропуск (адаптер не реализован) |
| `unknown` | прочее | проверка доступности, пропуск |

TLS: системное доверие, затем bundled CA (`search.ca_bundle`,
`config/certs/russian_trusted_ca.pem`). Проверка сертификата не отключается.
Общая фабрика контекстов — `config.ssl_contexts()`; используется и реестром
(`_fetch`), и импортом открытых данных (`open_data._download`). Относительные
ссылки каталога разрешаются от финального URL после редиректов.

## Адаптеры

- `eis_browser.py` — живой сбор расширенного поиска ЕИС (браузер Edge, fallback
  RSS), фильтрация по профилю/региону/срокам, сквозная дедупликация по
  каноническому ключу.
- `eis.py` — импорт XML/ZIP-выгрузок ЕИС (через общий импортёр с дедупликацией).
- `open_data.py` — импорт CSV/ZIP открытых данных по прямой ссылке или из файла
  (TLS-fallback на bundled CA). Файл без закупочных колонок — аккуратный пропуск
  (`ValueError` → статус `skipped`), а не ошибка сбора.

Сквозная дедупликация между источниками — в `tendermonitor/dedup.py`
(канонический ключ `num:`/`guid:`/`pair:`), слияние записей — в `importer.py`.
