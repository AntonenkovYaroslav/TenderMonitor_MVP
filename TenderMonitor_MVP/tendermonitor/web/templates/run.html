Как это работает

  • Задание запускает ту же команду, что и консоль: python -m tendermonitor.cli monitor-eis — с параметрами --region, --limit, --pages, --per-page, --days, --keywords, --category.
  • Глубина и сроки поиска по умолчанию берутся из блока search в config/keywords.json; поля формы переопределяют их на один запуск. Больше страниц/карточек — дольше сбор.
  • Сбор оставляет закупки с подтверждённым регионом и релевантностью не ниже «Средняя»; просроченные по сроку подачи пропускаются (если включено search.skip_expired).
  • Обычный сбор занимает 1–2 минуты, панель при этом работает; статус и лог — на странице задания.
  • Найденные закупки попадают в ту же базу data/tenders.db и в Excel-отчёт.
  • Одновременно выполняется только одно задание — повторный запуск блокируется.
