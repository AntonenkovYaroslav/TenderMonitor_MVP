Как формируется релевантность и проверка региона

Классификатор сопоставляет ключевые фразы из {{ scoring.groups|length }} направлений («{{ scoring.groups|join('», «') }}») по основам слов: «ремонт дороги» находит «ремонта дороги». Совпадение в заголовке даёт {{ scoring.weights.title_weight }} баллов, в описании/адресе/заказчике — {{ scoring.weights.other_weight }}. Подтверждённый регион добавляет +{{ scoring.weights.region_bonus }}, неподтверждённый отнимает {{ scoring.weights.region_penalty }}; итог ограничивается диапазоном 0–100.

Стоп-фразы профиля ({{ scoring.stop_phrases|length }} шт.: {{ scoring.stop_phrases[:6]|join(', ') }}…) в заголовке снижают балл на {{ scoring.weights.stop_penalty }} — так отсекается нерелевантный шум (мебель, ИТ-оборудование, ГСМ, питание, клининг). Отрицания («не», «без», «кроме», «исключая») рядом с фразой отменяют совпадение. Веса и пороги настраиваются в config/keywords.json.

Пороги: «Высокая» — от {{ scoring.thresholds.get('high', 65) }} баллов, «Средняя» — от {{ scoring.thresholds.get('medium', 35) }}, ниже — «Низкая». Направление — группа с наибольшим числом совпавших фраз; если совпадений нет вовсе, ставится «Не определено», а балл без региона опускается до нуля.

Регион проверяется по списку из {{ scoring.regions|length }} названий и городов ({{ scoring.regions[:5]|join(', ') }}…): сравниваются поле региона и адрес карточки. {% if scoring.region %}Регион поиска: «{{ scoring.region }}». {% endif %} Если источник не передал регион и адрес (так бывает у RSS-ленты и урезанных выгрузок открытых данных), проверить его не по чему — карточка получает метку «Проверить регион», а поля цены/заказчика/срока остаются пустыми: в таком источнике их просто нет. Пустые поля в списке скрыты; полные данные смотрите по ссылке на ЕИС.
