# Проверки Tender Monitor

Семь автономных наборов, 505 проверок. Каждый набор — обычный скрипт: создаёт
временные каталоги и БД, прогоняет проверки и печатает `ALL ... CHECKS PASSED`.
Ничего не устанавливает и не требует интернета (кроме живых сценариев, которые
в наборы не входят).

## Запуск

Из корня `TenderMonitor_MVP` (нужно виртуальное окружение, см. `install.bat`):

```bat
run_tests.bat
```

или по одному:

```bat
.venv\Scripts\python.exe tests\test_dedup.py
```

Пути внутри наборов относительные (`ROOT = Path(__file__).resolve().parents[1]`),
поэтому проверки работают после `git clone`/ZIP на любой машине. bat-файлы
принудительно CRLF (`.gitattributes`), кодировка вывода UTF-8 задана и в
`run_tests.bat`, и в самих скриптах — консоль Windows не ломает кириллицу.

## Изоляция

- Все наборы работают с временными БД (`tempfile.mkdtemp`): `db.DATA`, `db.DB`,
  `exporter.REPORTS` (и хранилище панели) подменяются до импорта модулей.
- Исключение — раздел 7 `test_iter3.py`: он проверяет настоящие CLI и `.bat`
  на реальном репозитории, поэтому перед запуском побайтово сохраняет
  `data/tenders.db`, `reports/tenders_report.xlsx`, `last_run.log` и
  восстанавливает их в `finally`. На время полного прогона закройте панель
  и планировщик, чтобы они не писали в эти файлы параллельно.
- `test_iter2.py` запускает headless chromium из Playwright на локальном
  HTML-fixture; браузер должен быть установлен (`playwright install chromium`).
- Браузерный сбор ЕИС в наборах не выполняется: сценарии Playwright
  подменяются стабами, сеть не нужна.
